# One Line, One Laugh: Roast Your Fridge

A single-line roast of my own fridge: its ice maker makes exactly 3 cubes a day, drops them at 3 a.m., and wakes me up to announce it like it just cured something.

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`.
